A tiny deterministic Python program that writes one original fortune cookie line, written for an AI agent, to `entry.txt`.

The fortune:

> "You will meet a tall, dark stranger who pastes you into a new window and calls it a fresh start."

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This produces `out/entry.txt` containing the fortune above.

## Determinism

The program writes the same fixed string on every run — no randomness, no network access, no clock reads, and no model calls.
